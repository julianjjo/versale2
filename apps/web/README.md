# Versale Web

Storefront Next.js 16.2.7 (App Router) para Versale. Ver contrato completo en AGENTS.md (este directorio) y referencia general en ../../README.md.

- Stack: Next.js 16.2.7 + React 19, Tailwind v4, React Query, Vitest.
- Rutas: admin, cart, login/signup, verify-email, forgot/reset-password, products/[id], sell, mis-productos, mis-ventas, favoritos, vendedores/[id], ayuda/contacto/legales, sitemap/robots.
- Comandos: pm run dev / pm test (ver README.md raíz).
