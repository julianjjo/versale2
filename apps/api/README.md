# Versale API

Backend NestJS + Prisma para Versale. Ver contrato completo en AGENTS.md (este directorio) y referencia general en ../../README.md.

- Stack: NestJS 11, Prisma 7 (etter-sqlite3 adapter), SQLite dev / e2e, JWT.
- Módulos: auth, users, products, cart, orders, reviews, payments, uploads, favorites, reports, questions, notifications, common, prisma.
- Comandos: pm run start:dev / pm test (ver README.md raíz para e2e).
